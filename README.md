# DigiPratibha 🎨💻

**DigiPratibha** is a **drag-and-drop portfolio builder designed for students** to create professional, personalized digital portfolios without needing advanced coding or web-design skills.

The platform makes portfolio creation simple by allowing users to select, customize, arrange, and manage different portfolio sections through an intuitive interface.

## ✨ Features

* 🖱️ **Drag & Drop Builder** — Easily arrange portfolio sections and components.
* 🎨 **Customizable Portfolio** — Personalize your portfolio according to your style.
* 👤 **Student-Friendly Profiles** — Add personal information, education, skills, achievements, projects, certifications, and more.
* 📂 **Project Showcase** — Display academic and personal projects in an organized manner.
* 🏆 **Achievements & Certifications** — Highlight accomplishments and certifications.
* 📱 **Responsive Design** — Designed to work across desktop, tablet, and mobile devices.
* 👀 **Live Preview** — Preview your portfolio while building it.
* 💾 **Easy Portfolio Management** — Create and update portfolio content easily.
* 🚀 **No-Code Experience** — Build a professional portfolio without writing code.

## 🎯 Problem Statement

Many students have skills, projects, certifications, and achievements but struggle to present them professionally online. Creating a personal portfolio from scratch often requires knowledge of HTML, CSS, JavaScript, or website-building tools.

**DigiPratibha solves this problem by providing a simple drag-and-drop platform where students can build their own professional portfolio with minimal technical knowledge.**

## 💡 Our Solution

DigiPratibha provides students with a structured and easy-to-use portfolio-building environment.

Users can:

1. Create their profile.
2. Select the sections they want to include.
3. Drag and drop sections into the desired order.
4. Add their personal information and achievements.
5. Customize the appearance of their portfolio.
6. Preview the final portfolio.
7. Share their professional profile with others.

The project is built using modern web technologies:

* **Frontend:** React.js
* **Build Tool:** Vite
* **Styling:** CSS
* **Backend:** Node.js / Express.js
* **Database:** MySQL

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/DigiPratibha.git
```

### 2. Navigate to the Project

```bash
cd DigiPratibha
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
